Animate Project Two

This is one of my Animate projects. This is a simple animation that I created using the Animate software.

The purpose of the project is an infographic to state a few benefits of getting good sleep.

The tools I used to create this animation include Rectangle Tool, Free Transform Tool, Star Tool, Text Tool, Adobe Assets, Keyframes/Frame-by-Frame Animation, Classic Tween, Layers, Audio.

Animate Project One

This is one of my Animate projects. This is a simple animation that I created using the Animate software.

The purpose of the project is to advertise Pink Sugar shampoo and conditioner, as well as it’s deal of being buy one get one 50% off!

The tools I used to create this animation include Rectangle Tool, Oval Tool, Text Tool, Keyframes/Frame-by-Frame Animation, Layers, Symbols, and an audio file.
